## Corrections

- Les neuf routes publiques indexables rendent les vrais composants React dans le HTML initial, pour tous les visiteurs. Aucune version spéciale selon le robot. Le pré-rendu attend les modules et les limites Suspense ; aucun segment caché ni script de streaming en ligne n'est nécessaire.
- Les styles propres à chaque route et les modules nécessaires sont annoncés depuis le manifeste Vite. Le contenu conserve donc sa mise en page sans JavaScript. Le navigateur hydrate ensuite l'interface ; un brouillon personnel de configuration reste restauré uniquement dans le navigateur.
- Le serveur utilise les tarifs publics réellement enregistrés, également transmis au client dans un bloc JSON inerte et échappé. La description de l'accueil suit ces tarifs, y compris CHF ou « sur devis ». Le cache de HTML anonyme est limité à 32 entrées/60 secondes, tient compte des valeurs tarifaires et ne conserve pas les échecs de rendu.
- Les titres des trois forfaits décrivent la création du site et leur usage. Un composant unique gère les métadonnées après navigation ; les effets locaux ne les écrasent plus.
- Données structurées `WebSite`, pages, fil d'Ariane et FAQ fondées sur les textes existants. Ni société fictive, ni adresse supposée, ni avis, ni note client, ni relation avec les références externes inventés. Le balisage FAQ ne promet pas de résultat enrichi.
- Aperçus Open Graph/Twitter utilisant le symbole de marque existant, sans remplacement du logo choisi.
- Cache navigateur d'un an avec `immutable` pour les JS, CSS et polices dont le nom contient le hash Vite. Les fichiers à nom stable gardent une durée courte.
- Le formulaire rendu par le serveur attend l'activation de JavaScript avant saisie/envoi ; un message sans JavaScript l'explique. Il ne peut pas envoyer par défaut les coordonnées dans une URL GET.
- Les liens Mentions légales et Confidentialité sont accessibles au pied de page et pointent vers des pages distinctes. Leurs textes restent provisoires, en attente des informations de Mathis ; ils restent hors indexation.

## Robots, domaine et suivi Google

Le `robots.txt` public autorise l'exploration générale et conserve les protections des API. Le sitemap XML expose neuf URL canoniques publiques. L'exclusion des comptes, dossiers privés, URL d'édition et textes légaux incomplets reste servie par meta et `X-Robots-Tag`. Les routes manquantes répondent réellement 404 et les anciens chemins connus redirigent.

Contrôle Cloudflare en lecture seule : zone active, protections spécifiques des robots IA désactivées, pas de règles personnalisées de blocage IA trouvées dans la liste des rulesets. Aucun paramètre de sécurité ou d'entraînement n'est modifié. Cela ne prouve pas à lui seul la visite effective de chaque moteur depuis ses adresses IP.

L'origine canonique demeure `https://gilmathis.com`. Mathis précise que `pixelito.dev` n'est pas encore acheté : ni canonical sur ce domaine ni adresse `contact@pixelito.dev` présentée comme active.

Le compte Google ouvert n'a pas accès à la propriété domaine `gilmathis.com` dans Search Console ; son sélecteur ne propose pas de propriété pour ce site. Aucune propriété n'est créée, aucun accès ajouté, aucun sitemap soumis pendant cet audit. L'indexation, les impressions, les clics, les positions et les citations par les IA ne sont donc pas validés.
